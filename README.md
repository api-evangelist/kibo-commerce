Kibo Commerce (KIBO) offers a unified, headless commerce and order management (OMS) platform for B2B and B2C ecommerce, with modular capabilities including AI-driven search, real-time inventory, order routing and fulfillment, subscriptions, pricing and promotions. Its Kibo Composable Commerce Platform is exposed through REST APIs (catalog, commerce, customer, fulfillment, inventory, location and more), API Extensions, SDKs and headless storefront starters documented at docs.kibocommerce.com.

**Areas:** Company · Commerce · E-Commerce · Headless Commerce · Order Management · B2B · Consumer · Inventory · Fulfillment

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Kibo Commerce: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
